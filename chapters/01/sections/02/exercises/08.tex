\begin{exercise}
Show that a map \(\nabla X \to \Pair{\NN / R}{\in}\) in \(\omegaSets\) is constant (where \(X\) is a set and \(R\) is a PER).
\end{exercise}

\begin{solution}
Let \(X\) be a set, \(R\) a PER, and \(f : \nabla X \to \Pair{\NN / R}{\in}\) a morphism in \(\omegaSets\).
Choose a code \(e \in \NN\) that tracks \(f\).
Then for all \(x \in X\) and \(n \in \NN\), \(e \cdot n\) is defined and \(e \cdot n \in f(x) \in \NN / R\). Since \(R\) is a PER, this implies that \(f(x) = f(y)\) for all \(x, y \in X\), so \(f\) is constant.
\end{solution}
